PROJECT ZULU LOGIN

Upload all files together to the same directory on your hosting.
Open zulu-orchid-falcon.html to sign in; successful sign-in opens zulu_index.html.
Uses your supplied Supabase project and existing email/password users.
Check Supabase Auth URL configuration for your deployed origin.

IMPORTANT: The dashboard guard is client-side. It hides the directory UI from signed-out users, but static HTML and linked sites are not server-protected. Protect any private data using Supabase RLS or server-side authorization.
